Hotel Management Project for Universidad Estatal a Distancia
Technologies: C# / .NET 10, Razor / Microsoft SQL Server / POO
Student: Felipe Brenes Conejo
In this project, a complete hotel management system was created, 
building APIRESTful and CRUD operations, using the MVC architecture and using Razor.
#######################################################################################
To run the project:
Open the visual studio solution
Compile the project
Create the database in SQL Server using the script on BaseDeDatos folder
Verify the route database are in local
Run the Project 1 and Project 2 at the same time (MVC + Api)
If everything is Ok, the data will appear on the website.
